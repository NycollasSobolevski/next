# Next Project
this project purpose is to be an physical and logical interface to controlling system generic functionalities (as media control, Discord ressources, live controller, etc ) and totally configurable. The physical controller is managed by modules, which each module has one function (volume control, for example) and all modules are connected to main-module that will send all data from physical component to PC and the software (ui), if have personalized configuration, will control the personalized setting.

## Repository Architecture 

this repository contains content of all project, including physical and logics schematics, with the follow structure: 
- ui: contains all content of user interface in operational system and personalized configuration;
- physical: contains code of all planned modules and your communication;
- Docs: have all current explanation of the project;
